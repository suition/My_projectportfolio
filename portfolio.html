Project 1: E-Wallet Transaction History. Using Python

The Transaction History serves as a record-keeping system inside the E‑wallet program. Every time a user sends money, the system automatically logs the details into a list of transactions. When the user selects View History, the program neatly displays all transactions in order, with numbering for easy reference. Alongside the list, the current balance is shown so users can track their remaining funds. This feature ensures transparency, accountability, and convenience by allowing users to review past activities, confirm successful transfers, and manage their spending habits.
